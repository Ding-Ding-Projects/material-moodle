    Where things live

    Upstream Moodle files stay as they are. Everything Material Moodle adds sits in a small overlay, so merging new Moodle releases stays simple.

    PathWhat it is
    public/theme/materialThe Material theme, a Boost child theme
    public/auth/passkeyPasskey sign-in and the passkey manager
    public/local/materialtoolsAdd a student, vocabulary pack, site wording, activity labels and the first-run configuration
    material/dockerDockerfile, Compose stack and container entrypoint
    material/deployerDesktop deployer (in progress)
    material/docsOne Markdown article per feature
    material/siteThis website

    Building the browser modules

    The plugins' browser modules are written by hand in amd/src. Moodle loads amd/build, so rebuild after every change. The script does not need Moodle's Grunt toolchain.

    material/scripts/build-amd.sh
