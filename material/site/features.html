    Features

    Material Moodle adds three plugins, a Docker stack and a desktop deployer to Moodle 6. Each card opens a detailed article.

    Theme and interface

    theme_material

    Material 3 theme

    One seed colour builds the full light and dark palette, with rounded shapes, density and motion levels.

    Read the article     theme_material

    Motion and reduced motion

    Expressive, calm or off. Devices that ask for reduced motion always get the calm version.

    Read the article     theme_material

    Command palette and regex builder

    Ctrl+Shift+F searches courses, page links and settings. Pattern blocks build a regular expression for you.

    Read the article     theme_materialIn progress

    Regex on every search box

    Filter boxes across Moodle get the same Regex and Ignore case switches and the same blocks.

    Read the article     theme_materialIn progress

    Right-click menu

    A Material menu with shortcuts for links, images, code, selected text and the page itself.

    Read the article     theme_material

    Copy buttons on code

    Every code block gets a Copy button that confirms when the text is on the clipboard.

    Read the article     theme_material

    Celebrations

    Success messages burst with confetti; errors shake and flash so they are not missed.

    Read the article     theme_material

    Configurable sign-in page

    Your own heading, text, labels and optional photo beside a large passkey button.

    Read the article

    Sign-in and accounts

    auth_passkey

    Passkey sign-in

    Sign in with a fingerprint, face, screen lock or security key. Passwords keep working.

    Read the article     auth_passkey

    Passkey manager

    Each person adds, renames and removes their own passkeys from their preferences.

    Read the article     local_materialtools

    Add a student

    Creates the account and a Discord message with the username and password in separate code blocks.

    Read the article     local_materialtools

    Forced password change and optional passkey

    New students choose their own password, then may add a passkey. The passkey step can be skipped.

    Read the article

    Words and labels

    local_materialtools

    Custom vocabulary pack

    Upload a JSON file of replacement words, shown only to the students and cohorts you choose.

    Read the article     local_materialtools

    Site wording

    Rename Teacher, Student and Assignment across the whole site from one page.

    Read the article     local_materialtoolsIn progress

    Activity type labels

    Give one assignment its own type label, such as "Dropbox", without renaming every assignment.

    Read the article
