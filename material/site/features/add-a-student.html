    Features ›

    Add a student

    Creates the account and a Discord message with the username and password in separate code blocks.

    Availablelocal_materialtools

    The form

    Site administration › Users › Material tools › Add a student.

    • First and last name are required.
    • Username is optional: empty means firstname.lastname in lower case, with a number added when it is taken.
    • Email is optional. Without one, email is switched off for the account so Moodle does not ask the student to complete a profile.
    • Temporary password: generate one (two words and a number by default) or type your own. Both follow the site password policy.
    • Optional cohort, course enrolment and custom vocabulary.

    The credentials message

    After Create student, the page shows the password once and a message with Copy for Discord. Discord renders each fenced block with its own copy button, so the student copies the username and the password separately.

    **{sitename}** sign-in for {fullname}
{siteurl}
Username:
```
{username}
```
Password:
```
{password}
```
You will choose a new password the first time you sign in. After that you can add a passkey for faster sign-in.

    The template is editable under Student account settings, with the placeholders {sitename}, {siteurl}, {fullname}, {firstname}, {username} and {password}.

    Security

    The temporary password is shown once and never stored in plain text, and the student must change it at first sign-in. Send the message in a direct message, not a public channel. The tool needs the local/materialtools:createstudents capability (managers by default).
