    Features ›

    Material 3 theme

    One seed colour builds the full light and dark palette, with rounded shapes, density and motion levels.

    Availabletheme_material

    What it does

    Material is a child theme of Boost that restyles every Moodle page in Material 3: tonal colour roles, rounded shapes, Material type, elevated surfaces, filled and tonal buttons, outlined fields, menus, dialogs, alerts, tabs, tables and code blocks.

    P 40 PC 90 SC TC P 80 PC 30 Dark

    This website uses the same palette, generated from the default seed #8B5000.

    One seed colour

    classes/palette.php turns the seed into the Material 3 role table (primary, secondary, tertiary, error, success, the surface container ladder, outline, inverse roles and scrim). Primary sits at tone 40 in light mode and tone 80 in dark mode. The roles are written as CSS custom properties such as --md-sys-color-primary, and Bootstrap's variables are mapped onto them, so core Moodle components follow the palette.

    Tones are approximated in HSL so the generator has no dependencies. Colours are close to, but not identical with, the reference Material Color Utilities output.

    Light and dark mode

    Turn on Colour modes in the Boost settings. People then choose light, dark or automatic from the user menu and the Material palette follows. The Docker first run turns colour modes on for you.

    Fonts

    Roboto Flex (default), Inter, Atkinson Hyperlegible Next or the device font. All fonts ship with the theme, so no font is loaded from another website. Roboto Mono is used for code.

    Settings

    SettingNameDefault
    Seed colourtheme_material | seedcolor#8B5000
    Fonttheme_material | fontRoboto Flex
    Corner roundnesstheme_material | radius24 px
    Densitytheme_material | densityComfortable
    Motiontheme_material | motionExpressive

    Find them under Site administration › Appearance › Themes › Material. Saving any of them purges the theme cache.

    Good to know

    • The generator clamps saturation but does not check contrast. Pick a seed with mid lightness.
    • Three-digit colours such as #abc are expanded; anything that is not a hex colour falls back to #8B5000.
