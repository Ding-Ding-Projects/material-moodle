1.0.0

20 November 2026 · Based on Moodle 6.0dev

Added

  • Material 3 theme (theme_material) with one seed colour for the light and dark palette, fonts bundled locally, corner roundness, density and three motion levels.
  • Ctrl+Shift+F command palette with a visual regex builder, copy buttons on code, celebrations for success and error messages, and a configurable sign-in page.
  • Passkey sign-in (auth_passkey) with a personal passkey manager and an optional passkey step after a new account's first sign-in.
  • Material tools (local_materialtools): Add a student with a Discord-ready credentials message and a forced password change, the custom vocabulary pack, and site wording for Teacher, Student and Assignment.
  • Docker stack with PostgreSQL, Moodle and cron, plus optional Cloudflare quick and named tunnels.
  • This website, with a working demo of the theme.

Still in progress

  • Desktop deployer, the regex builder on page search boxes, the right-click menu in Moodle, activity type labels and the guided Cloudflare sign-in.
