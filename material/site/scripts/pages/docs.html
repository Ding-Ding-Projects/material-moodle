Install

On a Linux server with or without Docker, one command installs everything and prints your link. See Deploy for the options.

bash <(curl -fsSL https://raw.githubusercontent.com/Ding-Ding-Projects/material-moodle/main/material/install.sh)

Building the browser modules

The plugins' browser modules are written by hand in amd/src. Moodle loads amd/build, so rebuild after every change. The script does not need Moodle's Grunt toolchain.

material/scripts/build-amd.sh
