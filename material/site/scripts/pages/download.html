What a release contains

Docker stack bundle

material-moodle-stack-<version>.zip with the Compose file and .env.example.

Plugin packages

The theme, passkey and Material tools plugins as zips for an existing Moodle 6 site.

Container image

ghcr.io/ding-ding-projects/material-moodle, tagged latest and per release.

Desktop deployer

Installers for Windows, macOS and Linux will be attached once the app is finished. They are not code signed, so your system may warn before opening them.

In progress

Release tags look like material-v1.0.0-42: the version, then the build number, so every build has a unique tag. Each release also has a dim sum code name.

Install the plugins on an existing site

The plugins require Moodle 6. Unzip each package into its folder, then visit Site administration to finish the upgrade.
