Activity type labels

Give one assignment its own type label, such as "Dropbox", without renaming every assignment.

In progresslocal_materialtools

Intended behaviour

Each activity can show its own type name without changing what it is. One assignment can appear as a Dropbox, another as a Lab report, while both stay ordinary assignments with the same permissions, grading and reports.

  • Type label per activity, up to 100 characters. An empty label brings back the standard name.
  • Quick post buttons such as Post a new Dropbox, defined one Label|modname per line, for example Dropbox|assign.
  • Personal titles such as "Coach" for the whole site or one course. Roles are unchanged.

Labels and titles never change roles, capabilities or module types; they are display names only.

Status

Storage, the database tables and parts of the course page display are in the repository. The editing interface, the upgrade step, privacy coverage and backup support are still being built.
