Cloudflare tunnel

A free quick link with no account, or a named tunnel on your own domain.

Available in the Docker stackGuided sign-in in progress

Quick tunnel

No Cloudflare account needed. Good for trying the site from another device. Choose the quick link in the installer menu (or MM_ACCESS=quick), and it prints the address. To switch an existing stack by hand, set MOODLE_WWWROOT=auto in .env, then:

docker compose --profile quicktunnel up -d
docker compose logs quicktunnel | grep -o 'https://[a-z0-9-]*\.trycloudflare\.com'
The address changes every time the tunnel restarts, and passkeys added on one address do not work on the next. Do not use a quick tunnel for a site people rely on.

Named tunnel

  1. In the Cloudflare dashboard, create a tunnel and copy its token.
  2. Add a public host name for the tunnel with service http://moodle:80.
  3. Set the token and the address in .env and start the profile.
CLOUDFLARE_TUNNEL_TOKEN=<token>
MOODLE_WWWROOT=https://moodle.example.org
docker compose --profile tunnel up -d

Guided sign-in

The desktop deployer will set up a named tunnel without the dashboard: it shows the Cloudflare sign-in link, waits for your approval, creates the tunnel and the DNS record, and restarts the stack. This part is in progress.

Security

Only the Moodle service is exposed through the tunnel; PostgreSQL stays on the private network. Keep the tunnel token in .env, never in the repository or a support message.
