Command palette and regex builder

Ctrl+Shift+F searches courses, page links and settings. Pattern blocks build a regular expression for you.

Availabletheme_material

What it finds

Press Ctrl Shift F (Cmd Shift F on a Mac), or select the Search button in the top bar.

  • Courses the signed-in person is enrolled in.
  • Pages linked from the current page: navigation, course index, user menu, drawers, breadcrumbs and footer.
  • Search all courses for "…", which opens Moodle's course search.
  • Search site settings for "…", for people who can configure the site.

The regex builder

Under the search field, pattern blocks append a piece of a regular expression, so nobody has to remember the syntax.

BlockPattern
Starts with / Ends with^ / $
Anything.*
Digit / Letter / Space\d / [A-Za-z] / \s
Word edge\b
One or more / Optional / Either+ / ? / |
Group start / Group end( / )

Regex switches between a regular expression and a plain text search; Ignore case is on by default. Both are remembered in the browser. While a pattern does not compile, the status reads "Pattern is incomplete" and no results are listed.

Keyboard

KeyAction
Ctrl Shift FOpen, or close when open
Up / DownMove through results
EnterOpen the highlighted result
EscClose and return focus to where it was

The dialog is modal, the field is a combobox that controls a listbox, and the match count is announced politely to screen readers.

Try it

This website has its own command palette built the same way. Press Ctrl Shift F now, or open the demo to search sample Moodle courses.

Limits

In Moodle the palette does not yet list every site setting or every activity in a course, and a result opens its page rather than highlighting one element.
