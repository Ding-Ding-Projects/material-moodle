Copy buttons on code

Every code block gets a Copy button that confirms when the text is on the clipboard.

Availabletheme_materiallocal_materialtools

What it does

Every <pre> block gets a Copy button in its top corner. It copies the text without a trailing newline and reads Copied for 1.5 seconds. Code blocks added later, such as a forum reply loaded by JavaScript, get a button too.

php admin/cli/purge_caches.php

For plugin authors

Any element with data-md-copy becomes a copy button. data-md-copy="some-id" copies the text of the element with that id; an empty data-md-copy with data-md-copy-text copies that text. Mark a block data-md-no-copy to leave it alone.

<code id="username">alex.student</code>
<button type="button" data-md-copy="username">Copy</button>

Settings

Copy buttons on code (theme_material | copybuttons), on by default. Copying uses the Clipboard API on HTTPS and localhost and falls back to a hidden text area elsewhere.
