Desktop deployer

One click deploys the stack to any Linux server you can reach over SSH.

In progressmaterial/deployer

Intended behaviour

Material Moodle Deployer is a desktop app for Windows, macOS and Linux. It puts the Docker stack on a server and publishes it through a Cloudflare tunnel, without a terminal.

  1. ConnectServer address, user and a password or SSH key. The host key fingerprint must be accepted the first time.
  2. DeployDocker is checked, the stack is uploaded, .env is written with generated passwords and the containers start.
  3. PublishA quick tunnel, a named tunnel with guided Cloudflare sign-in, or a pasted tunnel token.

Each job is a list of steps with live status and logs; a failed step can be retried without starting over. Secrets are kept in the operating system's protected storage.

Status

The deployment engine is being written and the user interface does not exist yet, so there is no installer to download today. Use the Docker stack directly in the meantime.
