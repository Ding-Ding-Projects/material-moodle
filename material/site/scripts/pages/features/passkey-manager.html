Passkey manager

Each person adds, renames and removes their own passkeys from their preferences.

Availableauth_passkey

What it does

The page is linked as Passkeys from each person's Preferences page.

  • Add a passkey: optionally name it, for example "My phone", then follow the device prompt. The same authenticator cannot be registered twice.
  • Each passkey shows its name, when it was added and when it was last used.
  • Rename changes the name; Remove asks for confirmation first.
My phoneLast used: today
Security keyNever

If passkey sign-in is not enabled for the site, the page says so: passkeys can be added but not used until an administrator enables the plugin.

Limits

People manage only their own passkeys. There is no administrator view of another person's passkeys yet, and no notification is sent when a passkey is added or removed.
