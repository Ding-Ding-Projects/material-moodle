Right-click menu

A Material menu with shortcuts for links, images, code, selected text and the page itself.

In progresstheme_material

What is in the menu

Right-click onActions
Selected textCopy (Ctrl+C), Search for "…"
A linkOpen (Enter), Open in new tab (Ctrl+Click), Copy link address
An imageOpen image in new tab, Copy image address
CodeCopy code
AnywhereSearch (Ctrl+Shift+F), Back (Alt+Left), Reload (F5), Copy page address, Print (Ctrl+P), Back to top (Home)

Shift + right-click always opens the browser's own menu, and text fields, editors and selects keep the browser menu so spelling suggestions and paste still work.

Accessibility

The menu is a role="menu" of menu items, kept inside the window and focused when it opens. Up and Down move, Escape or Tab close it and return focus.

Status

The module theme_material/contextmenu is written but not loaded by the theme yet, and its labels are not in the language file. This website has a working version: right-click anywhere on this page.
