Regex on every search box

Filter boxes across Moodle get the same Regex and Ignore case switches and the same blocks.

In progresstheme_material

How it works

A small .* button appears beside every search field on a page: input[type=search], Moodle's simple search forms, and fields named search, q or query. It opens a pop-over with the Regex and Ignore case switches and the same pattern blocks as the command palette.

In regex mode, the visible lists and tables in the main region (table rows, list items, activities, course cards, forum posts) are filtered live. Pressing Enter still runs Moodle's own search with the text as typed. Search boxes added to the page later are picked up automatically.

Status

The module theme_material/searchbars is written but not loaded by the theme yet. The regex builder is available today inside the command palette.

On this website

Every page of this website has a search bar under the tabs. Select Regex builder beside it to show the blocks.
