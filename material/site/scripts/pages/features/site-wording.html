Site wording

Rename Teacher, Student and Assignment across the whole site from one page.

Availablelocal_materialtools

Fields

FieldWhat changes
TeacherThe site-wide name of the editing teacher role
Non-editing teacherThe site-wide name of the non-editing teacher role
StudentThe site-wide name of the student role
Assignment (one) / Assignment (many)The assignment activity name in the current language

The names apply on every page, for everyone, including every assignment that is posted. Leave a field empty to keep the standard name. Assignment names are stored as a local language override, the same file Moodle's language customisation tool uses.

Limits

Assignment names are saved for the language of the person saving the form; repeat in each installed language. To give one assignment its own type name, use activity type labels.
