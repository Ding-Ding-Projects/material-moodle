Custom vocabulary pack

Upload a JSON file of replacement words, shown only to the students and cohorts you choose.

Availablelocal_materialtools

What it does

A vocabulary pack replaces interface words with your own words, for the signed-in people you choose. For example, "Hand-in" wherever the interface says "Submission". Signed-out pages always keep the original wording. Matching is whole-word and case-insensitive, and code, form fields and editors are never changed.

The Vocabulary page covers the file format, upload and audiences in full.

Who sees it

  • Nobody: the pack stays stored but unused.
  • Everyone signed in.
  • Selected students and cohorts (default): people chosen on the page or on Add a student, plus members of chosen cohorts.

Security

The file is validated in full before anything is stored, so a rejected file never applies partially. Values are inserted as text, never as HTML, and the pack is only sent to eligible signed-in people.
