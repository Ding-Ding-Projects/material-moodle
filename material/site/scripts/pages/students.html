Students

Add a student in one form and paste their sign-in details straight into Discord. Username and password each sit in their own code block, so one tap copies each.

The flow

  1. Fill in the nameThe username is made from the name if you leave it empty. Email is optional.
  2. Create studentA temporary password is generated, for example two words and a number.
  3. Copy for DiscordOne button copies the whole message. Send it as a direct message.
  4. First sign-inThe student must choose a new password, then may add a passkey.
