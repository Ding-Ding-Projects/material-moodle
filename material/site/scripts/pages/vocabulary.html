Pack file format

A pack is a UTF-8 JSON object with schemaVersion 1 and an entries object of original words and replacements.

{
  "schemaVersion": 1,
  "name": "Our school words",
  "entries": {
    "submission": "hand-in",
    "assignment": "task"
  }
}
RuleLimit
File sizeAt most 256 KB
Keys1 to 160 characters
ValuesText of 1 to 1,000 characters
NestingAt most 8 levels deep
Duplicate keysRejected
nameOptional, shown as the headline when the pack is applied

Any failed rule rejects the whole file with a specific message, and the previous pack stays in place.

Upload and audience

  • Choose a file on Site administration › Users › Material tools › Custom vocabulary, or drop a .json file anywhere on the site as a manager.
  • Pick who sees it: nobody, everyone signed in, or selected students and cohorts (the default).
  • Tick Custom vocabulary on Add a student to choose a new student straight away.
  • Signed-out pages, guests and people outside the audience always see the original wording.
